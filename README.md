# OpenSight for Chromium

OpenSight makes websites easier to see, read, and navigate with visual filters, readability controls, motion reduction, zoom, and focus aids.

## Download

Download the latest Chromium package from the shared Drive folder:

https://drive.google.com/drive/folders/1xxkRx738J0PPmgrdQfOELcnbCbmMjY24?usp=sharing

This build works with Chrome, Microsoft Edge, Brave, and other Chromium-based browsers.

## Install

1. Download the Chromium ZIP file and extract it.
2. Open `chrome://extensions` in Chrome, or the equivalent extensions page in your browser.
3. Turn on **Developer mode**.
4. Select **Load unpacked**.
5. Choose the extracted OpenSight folder containing `manifest.json`.
6. Pin OpenSight from the browser toolbar for quick access.

## Setup

1. Open a website you want to adjust.
2. Select OpenSight from the toolbar.
3. Choose **Site** to save settings only for the current website, or **Everywhere** for global defaults.
4. Turn on the visual, readability, or focus controls you need.
5. Use **Reset current settings** to return the selected scope to its defaults.

Keyboard shortcuts:

- `Alt/Option + Shift + G` — toggle grayscale
- `Alt/Option + Shift + I` — toggle inverted colors

## Notes

- Browser-internal pages such as `chrome://` and extension stores cannot be modified.
- Settings are saved with browser storage and can sync with your browser profile.
- To update an unpacked installation, replace the extracted folder with the new version and click **Reload** on the extensions page.
